- **Release notes you can control**: the update text shown in the dashboard is
  now a real changelog. Hand-written `release-notes/<tag>.md` wins; otherwise
  the workflow auto-generates the list of commits since the last release.
- **Deploy from macOS/Linux**: `scripts/deploy.sh` mirrors `deploy.ps1`
  (build, push, restart, health-check) for POSIX hosts.
- **Open factory AP control**: the leftover no-password "Factory-Moretti"
  profile can be disabled/enabled from Network → Wi-Fi (disabled by default
  on upgraded devices).
- Wi-Fi AP settings (SSID, security, bandwidth, split/combined bands) and the
  platform-true Wi-Fi toggle introduced in v0.5–v0.7 are included.
